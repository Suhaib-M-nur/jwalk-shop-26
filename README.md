# J WALK Shop 26 · محل 26

Interactive 3D model of Shop 26, ground floor, J WALK (Al-Jammawat Park, Madinah).

**View it:** https://suhaib-m-nur.github.io/jwalk-shop-26/

- Floor area 120 m², curved glass frontage 8.08 m, depth 10.24 m, clear ceiling height 4.00 m
- Views: overview, shopfront, inside and plan; empty shell or furnished; dimensions, neighbouring rooms and opening doors
- Geometry taken from the shop's DWG and ground-floor plan. Glazing height, sign band, walkway soffit and the overhead element's depth are estimates; the furniture is an illustrative layout.

A single self-contained `index.html` (three.js and fonts load from public CDNs).
